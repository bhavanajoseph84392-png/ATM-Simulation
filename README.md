# ATM Simulation System

## 📌 Project Overview

The **ATM Simulation System** is a Python-based console application that simulates basic ATM operations. It allows users to log in using their account number and PIN, check their account balance, deposit money, withdraw money, and view transaction history.

This project was developed as part of Python programming practice to understand object-oriented programming, conditional statements, loops, functions, and basic banking operations.

## 🎯 Objectives

- Develop a simple ATM application using Python.
- Understand Object-Oriented Programming (OOP) concepts.
- Implement account authentication using an account number and PIN.
- Perform basic banking transactions.
- Maintain a transaction history during program execution.
- Apply input validation and error handling.

## ✨ Features

- **User Authentication:** Log in using an account number and PIN.
- **Balance Enquiry:** Display the current account balance.
- **Cash Deposit:** Add money to the account.
- **Cash Withdrawal:** Withdraw money based on the available balance.
- **Transaction History:** View transactions performed during the current session.
- **Input Validation:** Validate user inputs according to the implemented rules.
- **Menu-Driven Interface:** Navigate between ATM operations through a console menu.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Concepts:** Object-Oriented Programming (OOP), classes, objects, methods, loops, conditional statements, and lists
- **Development Environment:** Python IDLE / Visual Studio Code
